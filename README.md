# 🛡️ KnightFight

**KnightFight** is an action-packed arcade game developed with **Godot
Engine**, where fast reflexes and positioning are the key to survival.

You play as a lone knight running through a dangerous battlefield while
enemies approach from **all directions**. Your mission is simple:
**fight, survive, and defeat as many enemies as possible**.

------------------------------------------------------------------------

## 🎮 Game Concept

KnightFight combines **movement, combat, and survival mechanics** into a
fast-paced experience.

As the player: - You are constantly on the move - Enemies spawn and
close in from multiple directions - You must attack, dodge, and
reposition to stay alive - The difficulty increases as the game
progresses

The game focuses on: - ⚔️ Responsive combat\
- 🧠 Quick decision-making\
- 🏃 Constant movement and positioning

------------------------------------------------------------------------

## 🧩 Features

-   Real-time combat system\

## ▶️ How to Run the Project

1.  Download or clone this repository:

    ``` bash
    git clone https://github.com/your-username/KnightFight.git
    ```

2.  Open **Godot Engine**\

3.  Click on **Import**\

4.  Select the `project.godot` file inside the project folder\

5.  Press **Run** ▶️
